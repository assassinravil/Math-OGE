1 Числа и вычисления занятия 1–2, повторение

Дроби

a/b + c/d = (ad + bc)/(bd)
a/b · c/d = ac/(bd)
a/b : c/d = ad/(bc)
Порядок: скобки → степени → × и : → + и −.

Проценты

p% от a = a · p/100.
Увеличить на p%: a · (1 + p/100).
Уменьшить на p%: a · (1 − p/100).
Сколько процентов b от a: b/a · 100%.

Сравнение и прямая

Сравнить корни: возвести в квадрат.
√10 < 3,2, т. к. 10 < 10,24.
Округление: смотрим на следующую цифру (≥ 5 — вверх).

Стандартный вид

a · 10ⁿ, где 1 ≤ a < 10.
45 000 = 4,5 · 10⁴, 0,0032 = 3,2 · 10⁻³.

2 Степени, корни, формулы сокращённого умножения повторение 7–8 кл.

Степени

aᵐ · aⁿ = aᵐ⁺ⁿ,  aᵐ : aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ,  (ab)ⁿ = aⁿbⁿ
a⁰ = 1,  a⁻ⁿ = 1/aⁿ

Квадратные корни

√(ab) = √a · √b,  √(a/b) = √a / √b
(√a)² = a,  √(a²) = |a|
Вынесение: √50 = 5√2.
Избавление от корня в знаменателе: 1/√2 = √2/2.

ФСУ

(a ± b)² = a² ± 2ab + b²
a² − b² = (a − b)(a + b)
a³ ± b³ = (a ± b)(a² ∓ ab + b²)

Алгебраические дроби

Сокращать можно только множители.
ОДЗ: знаменатель ≠ 0.
Общий знаменатель — НОК знаменателей.

3 Уравнения занятия 9–10, повторение

Квадратное уравнение

ax² + bx + c = 0
D = b² − 4ac
x = (−b ± √D) / (2a)
D > 0 — два корня, D = 0 — один, D < 0 — нет.

Теорема Виета

x₁ + x₂ = −b/a,  x₁ · x₂ = c/a.
Приведённое x² + px + q: сумма −p, произведение q.

Неполные

ax² + bx = 0 → x(ax + b) = 0.
ax² + c = 0 → x² = −c/a.

Целые уравнения высших степеней

Разложить на множители (вынести, сгруппировать).
Замена: биквадратное ax⁴ + bx² + c = 0, t = x² ≥ 0.

Дробные уравнения

1) ОДЗ: знаменатели ≠ 0.
2) Умножить на общий знаменатель.
3) Решить и проверить корни по ОДЗ.

4 Неравенства и системы занятия 13–17, повторение

Линейные

При делении на отрицательное число знак меняется.
Система — пересечение решений, совокупность — объединение.

Квадратные

Найти корни, нарисовать параболу, взять нужные промежутки.
x² − 4 < 0 → −2 < x < 2.

Метод интервалов

1) Корни множителей на прямую.
2) Знак в крайнем правом промежутке.
3) Чередовать знаки (кроме чётной кратности).
Нули знаменателя — всегда выколоты.

Системы уравнений

Подстановка: выразить и подставить.
Сложение: уравнять коэффициенты.
Графически: точки пересечения графиков.

5 Функции и графики занятия 4–8

Свойства

D(f) — допустимые x, E(f) — значения.
Нули: f(x) = 0.
Чётная: D(f) симметрична и f(−x) = f(x); нечётная: D(f) симметрична и f(−x) = −f(x).
Схема: D, E, нули, знаки, монотонность, наиб./наим., чётность.

y = kx + b

k — наклон (k > 0 — возрастает), b — пересечение с Oy.
Параллельны ⇔ равные k.

y = k/x

k > 0 — I и III четверти, k < 0 — II и IV.
y = k/(x − m) + n: асимптоты x = m, y = n.

Парабола

y = a(x − m)² + n → вершина (m; n).
y = ax² + bx + c: x₀ = −b/(2a)
a > 0 — ветви вверх; (0; c) — пересечение с Oy.

y = √x, y = |x|, y = x³

√x: x ≥ 0, y ≥ 0.
|x|: «галочка», чётная.
x³: нечётная, возрастает.

№22: графики

Сократили дробь — выколоть точку.
|f(x)| — отразить низ вверх.
Особые m: вершины, выколотые точки, стыки кусков.

6 Текстовые задачи занятия 11–12

Движение

s = v · t.
Навстречу: v₁ + v₂, вдогонку: v₁ − v₂.
По течению: v + vтеч, против: v − vтеч.

Работа

A = p · t (работа = производительность × время).
Вся работа = 1. Вместе: p₁ + p₂.

Смеси и проценты

Масса вещества = масса раствора × концентрация.
Вещество при смешивании складывается.

7 Прогрессии занятия 19–21

Арифметическая

aₙ = a₁ + d(n − 1)
Sₙ = (a₁ + aₙ) · n / 2
Sₙ = (2a₁ + d(n − 1)) · n / 2

Геометрическая

bₙ = b₁ · qⁿ⁻¹
Sₙ = b₁(qⁿ − 1) / (q − 1)
q ≠ 1.

8 Вероятность и статистика занятия 22–23

Классическая вероятность

P = m / n
m — благоприятные исходы, n — все.
0 ≤ P ≤ 1.

Противоположное событие

P(Ā) = 1 − P(A).
Независимые: P(A и B) = P(A) · P(B).

Комбинаторика

Перестановки: n! = 1 · 2 · … · n.
Правило умножения: m · n вариантов.

Статистика

Среднее — сумма / количество.
Медиана — середина упорядоченного ряда.
Мода — самое частое, размах — max − min.
