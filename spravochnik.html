1 Углы и параллельные прямые занятие 1

Смежные и вертикальные

Смежные: сумма 180°.
Вертикальные: равны.

Параллельные прямые и секущая

Накрест лежащие — равны.
Соответственные — равны.
Односторонние — сумма 180°.
Обратно — признаки параллельности.

Аксиома параллельных

Через точку вне прямой проходит только одна прямая, параллельная данной.

2 Треугольник занятия 1–2

Сумма углов

∠A + ∠B + ∠C = 180°
Тупой или прямой угол — не больше одного.

Внешний угол

Равен сумме двух углов треугольника, не смежных с ним.

Неравенство треугольника

a < b + c
Против большей стороны — больший угол.

Медиана, биссектриса, высота

Медиана — в середину стороны.
Биссектриса — делит угол пополам.
Высота — перпендикуляр к стороне.
Три медианы пересекаются в одной точке и делятся ею 2 : 1 от вершины.

Признаки равенства

I — две стороны и угол между ними.
II — сторона и два прилежащих угла.
III — три стороны.

Средняя линия

Соединяет середины двух сторон. Параллельна третьей стороне и равна её половине.

3 Равнобедренный и равносторонний занятие 2

Равнобедренный (AB = BC)

Углы при основании равны: ∠A = ∠C = (180° − ∠B) : 2.
Медиана, биссектриса и высота к основанию совпадают.
Признак: два равных угла → равнобедренный.

Равносторонний

Все углы 60°.
h = a√3 / 2  ·  S = a²√3 / 4
R = a√3 / 3, r = a√3 / 6, R = 2r.

4 Прямоугольный треугольник занятия 3–4, 7

Углы

Острые углы: ∠A + ∠B = 90°.
Катет против 30° = гипотенуза : 2.

Медиана к гипотенузе

Равна половине гипотенузы. Середина гипотенузы — центр описанной окружности: R = c / 2.

Теорема Пифагора

c² = a² + b²
Обратная: если c² = a² + b², угол против c — прямой.
Тройки: 3-4-5, 5-12-13, 8-15-17, 7-24-25, 20-21-29, 9-40-41.

Высота к гипотенузе

h = ab / c
h² = AH · HB,  a² = c · (проекция a).
∠BCH = ∠A, ∠ACH = ∠B.

Синус, косинус, тангенс, котангенс

sin A = противолежащий / гипотенуза
cos A = прилежащий / гипотенуза
tg A = противолежащий / прилежащий
ctg A = прилежащий / противолежащий = cos A / sin A
sin²A + cos²A = 1  ·  tg A = sin A / cos A

5 Подобие занятия 5–6

Признаки подобия

I — два угла.
II — две стороны пропорциональны, углы между ними равны.
III — три стороны пропорциональны.

Коэффициент подобия k

Стороны, высоты, медианы, периметры — в k раз.
Площади — в k² раз.

Прямая, параллельная стороне

Отсекает треугольник, подобный данному.

Свойство биссектрисы

Делит сторону на отрезки, пропорциональные прилежащим сторонам: AL : LC = AB : BC.

6 Площадь треугольника, теоремы синусов и косинусов занятия 4, 8

Формулы площади

S = ½ · a · h
S = ½ · a · b · sin C
S = √(p(p − a)(p − b)(p − c)) — Герон
S = p · r  ·  S = abc / (4R)
p — полупериметр.

Соотношения площадей

Медиана делит треугольник на два равновеликих.
Общая высота → площади относятся как основания.

Теорема синусов

a / sin A = b / sin B = c / sin C = 2R

Теорема косинусов

c² = a² + b² − 2ab · cos C
cos C < 0 — угол C тупой.

7 Многоугольники и четырёхугольники занятия 9–12

Многоугольник

Сумма углов выпуклого n-угольника: 180° · (n − 2).
Угол правильного n-угольника: 180° · (n − 2) / n.
Сумма внешних углов — 360°.

Параллелограмм

Противоположные стороны и углы равны.
Диагонали делятся точкой пересечения пополам.
Сумма соседних углов 180°.
S = a · h = a · b · sin α

Прямоугольник

Диагонали равны.
S = a · b  ·  d² = a² + b²

Ромб

Диагонали перпендикулярны и являются биссектрисами углов.
S = ½ · d₁ · d₂ = a · h = a² · sin α

Квадрат

Все свойства прямоугольника и ромба.
S = a² = d² / 2  ·  d = a√2

Трапеция

Средняя линия (a + b) / 2, параллельна основаниям.
Равнобедренная: углы при основании равны, диагонали равны.
S = (a + b) / 2 · h

Любой выпуклый четырёхугольник

S = ½ · d₁ · d₂ · sin φ

8 Окружность занятия 13–16

Касательная

Перпендикулярна радиусу в точке касания.
Отрезки касательных из одной точки равны.

Хорды и секущие

Диаметр ⊥ хорде делит её пополам.
Пересекающиеся хорды: AE · EB = CE · ED.
Касательная и секущая: MA² = MB · MC.

Углы

Центральный угол = дуга.
Вписанный угол = половина дуги.
Вписанный угол, опирающийся на диаметр, — 90°.
Вписанные углы на одну дугу равны.
Угол между касательной и хордой = половина дуги.

Описанная окружность △

Центр — пересечение серединных перпендикуляров.
R = a / (2 sin A) = abc / (4S)

Вписанная окружность △

Центр — пересечение биссектрис.
r = S / p
Прямоугольный: r = (a + b − c) / 2.

Четырёхугольники и окружность

Вписанный: ∠A + ∠C = ∠B + ∠D = 180°.
Описанный: a + c = b + d.

Длина и площадь

C = 2πR  ·  S = πR²
Дуга α°: l = πRα / 180.
Сектор α°: S = πR²α / 360.

9 Векторы и координаты занятия 17–21

Действия

Сложение: правило треугольника (AB + BC = AC) и параллелограмма.
a − b = a + (−b).
k · a: длина |k| · |a|, при k < 0 направление меняется.

Коллинеарность

b = k · a. В координатах: x₁ / x₂ = y₁ / y₂.
k > 0 — сонаправлены, k < 0 — противоположно направлены.

Координаты

AB = (x₂ − x₁; y₂ − y₁)
|a| = √(x² + y²)
Середина: ((x₁ + x₂) / 2; (y₁ + y₂) / 2)
Расстояние: √((x₂ − x₁)² + (y₂ − y₁)²)

Уравнения

Окружность: (x − x₀)² + (y − y₀)² = R²
Прямая: ax + by + c = 0

Скалярное произведение

a · b = |a| · |b| · cos φ = x₁x₂ + y₁y₂
a · b = 0 ⇔ a ⊥ b.

10 Движения и подобие фигур занятие 22

Движения

Осевая и центральная симметрия, параллельный перенос, поворот. Сохраняют расстояния: фигура переходит в равную.

Оси симметрии

Равносторонний △ — 3, квадрат — 4, прямоугольник и ромб — 2, окружность — бесконечно много. Параллелограмм (общий) — 0, есть центр симметрии.
