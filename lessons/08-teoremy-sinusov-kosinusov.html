Теоремы синусов и косинусов. Площадь через синус

Синус и косинус углов от 0° до 180°, площадь треугольника через две стороны и угол, решение треугольников.

2 Теория 10–25 мин

Синус и косинус для 0° ≤ α ≤ 180° Точка на единичной полуокружности: x = cos α, y = sin α.
sin(180° − α) = sin α
cos(180° − α) = −cos α
Для тупого угла cos < 0. sin 90° = 1, cos 90° = 0.
tg α = sin α / cos α (α ≠ 90°), ctg α = cos α / sin α (α ≠ 0°, 180°).
sin 150° = sin 30° = ½; cos 120° = −cos 60° = −½.
Площадь через синус
S = ½ · a · b · sin C
Две стороны и угол между ними.
a = 6, b = 10, ∠C = 30° → S = ½ · 6 · 10 · ½ = 15.
Теорема синусов
a / sin A = b / sin B = c / sin C = 2R
R — радиус описанной окружности.
a = 10, ∠A = 30° → 2R = 10 : ½ = 20, R = 10.
Теорема косинусов
c² = a² + b² − 2ab · cos C
При C = 90° — теорема Пифагора. Найти угол: cos C = (a² + b² − c²) / (2ab).
a = 5, b = 8, ∠C = 60° → c² = 25 + 64 − 2 · 5 · 8 · ½ = 49, c = 7.
Какую теорему брать
  • Две стороны и угол между ними → косинусов.
  • Три стороны → угол по косинусам.
  • Сторона и противолежащий угол (или нужен R) → синусов.

Пример 1. Площадь

Стороны 6 и 10, угол между ними 30°. Найдите площадь.

Показать решение

Решение. S = ½ · 6 · 10 · ½ = 15.

Ответ: 15.

Пример 2. Косинусы

a = 3, b = 8, ∠C = 60°. Найдите c.

Показать решение

Решение. c² = 9 + 64 − 2 · 3 · 8 · ½ = 49, c = 7.

Ответ: 7.

Пример 3. Синусы

a = 10, ∠A = 30°. Найдите радиус описанной окружности.

Показать решение

Решение. 2R = 10 / sin 30° = 20, R = 10.

Ответ: 10.

3 Интерактивная практика 25–45 мин

🎯 Тренажёр «Решаем треугольники»

Корни вводите как √3/2 или sqrt(3)/2. Засчитывается при 5 верных из 6.

Блок А. База

П1база

Найдите площадь треугольника, две стороны которого равны 6 и 10, а угол между ними 30°.

П2база

Найдите площадь треугольника со сторонами 8 и 5 и углом 150° между ними.

sin 150° = sin 30° = ½. S = ½ · 8 · 5 · ½ = 10.
П3база

Найдите sin 120° и cos 150°.

sin 120° = sin 60° = √3/2; cos 150° = −cos 30° = −√3/2.
П4база

В △ABC BC = 3, AC = 8, ∠C = 60°. Найдите AB.

П5база

В △ABC BC = 5, AC = 3, ∠C = 120°. Найдите AB.

c² = 25 + 9 − 2 · 5 · 3 · (−½) = 49.
П6база

В △ABC BC = 10, ∠A = 30°. Найдите радиус описанной окружности.

Блок Б. Посложнее

П7средний

В △ABC AB = 12, ∠C = 150°. Найдите радиус описанной окружности.

2R = 12 / sin 150° = 24.
П8средний

В △ABC AB = 6√2, ∠C = 45°. Найдите радиус описанной окружности.

2R = 6√2 / (√2/2) = 12.
П9средний

Стороны треугольника равны 5, 8 и 7. Найдите угол, лежащий против стороны 7.

cos C = (25 + 64 − 49) / 80 = ½ → C = 60°.
П10сложнее

Две стороны треугольника 7 и 8, угол между ними 120°. Найдите третью сторону.

c² = 49 + 64 + 56 = 169.

Какие из следующих утверждений верны?

  1. Площадь треугольника равна половине произведения двух его сторон на синус угла между ними.

Б3ОГЭ №24

Докажите формулу S = ½ · a · b · sin C.

Высота к стороне a: h = b · sin C (из прямоугольного треугольника; для тупого C — sin(180° − C) = sin C). S = ½ · a · h = ½ · a · b · sin C.
