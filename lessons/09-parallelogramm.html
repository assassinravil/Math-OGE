Многоугольники. Параллелограмм

Сумма углов выпуклого многоугольника, параллелограмм: определение, свойства, признаки. Биссектриса угла параллелограмма.

① Проверка ДЗ 0–10′ ② Теория 10–25′ ③ Практика 25–45′ ④ ОГЭ 45–55′ ⑤ Итог и ДЗ 55–60′ ★ Бонус

План занятия (60 минут)

  1. 0–10′ Проверка ДЗ занятия 8.
  2. 10–25′ Теория. Многоугольник → сумма углов (n − 2) · 180°. Лаборатория: тянуть вершины — противоположные стороны и углы остаются равными, AO = OC, BO = OD. Включить «Биссектрису ∠A»: AB = BK всегда.
  3. 25–45′ Тренажёр, затем П1–П10.
  4. 45–55′ ОГЭ №17 и №19. Биссектриса в параллелограмме — один из самых частых сюжетов №17.
  5. 55–60′ Шпаргалка, ДЗ. Начинаем раздел «Четырёхугольники».

Типичные ошибки: путают сумму углов (n − 2) · 180° с n · 180°; считают, что диагонали параллелограмма равны; в задаче с биссектрисой приравнивают AB к KC вместо BK; соседние углы считают равными.

2 Теория 10–25 мин

Выпуклый многоугольник n-угольник имеет n вершин и n сторон. Диагональ соединяет две несоседние вершины. Выпуклый — лежит по одну сторону от каждой прямой, содержащей его сторону.
  • Сумма углов выпуклого n-угольника: (n − 2) · 180°.
  • Сумма внешних углов (по одному при каждой вершине): 360°.
  • Число диагоналей: n(n − 3) / 2.
Шестиугольник: (6 − 2) · 180° = 720°. Если он правильный, каждый угол 720° : 6 = 120°.
Угол правильного многоугольника 140° → внешний 40° → n = 360° : 40° = 9.
Сумма углов четырёхугольника 360°, а не 180° · 4.
Параллелограмм Четырёхугольник, у которого противоположные стороны попарно параллельны: AB ∥ CD, AD ∥ BC.
  • Противоположные стороны равны, противоположные углы равны.
  • Диагонали точкой пересечения делятся пополам: AO = OC, BO = OD.
  • Углы, прилежащие к одной стороне, в сумме 180° (односторонние).
∠A = 70° → ∠C = 70°, ∠B = ∠D = 110°.
AC = 10, BD = 16 → AO = 5, BO = 8.
Диагонали параллелограмма в общем случае не равны и не перпендикулярны.
Признаки параллелограмма Четырёхугольник — параллелограмм, если:
  1. две его стороны равны и параллельны;
  2. противоположные стороны попарно равны;
  3. диагонали пересекаются и точкой пересечения делятся пополам.
AO = OC и BO = OD → ABCD — параллелограмм (признак 3).
«Одна пара сторон параллельна, другая — равна» — это не признак: так бывает у равнобедренной трапеции.
Биссектриса угла параллелограмма Биссектриса AK угла A (K ∈ BC) отсекает равнобедренный треугольник ABK:
∠BAK = ∠KAD = ∠BKA  ⇒  AB = BK
∠KAD = ∠BKA — накрест лежащие при AD ∥ BC.
BK = 15, KC = 9 → AB = 15, BC = 24, P = 2 · (15 + 24) = 78.
AB равна отрезку BK, прилежащему к вершине B, а не KC.
Биссектрисы соседних углов перпендикулярны: ½ · 180° = 90°.

Лаборатория: параллелограмм

Перетаскивайте вершины A, B, D — вершина C строится так, что ABCD остаётся параллелограммом. Одинаковым цветом отмечены равные элементы.

↳ Разбор примеров

Пример 1. Сумма углов

Найдите сумму углов выпуклого восьмиугольника.

Показать решение

Решение. (8 − 2) · 180° = 6 · 180° = 1080°.

Ответ: 1080°.

Пример 2. Углы параллелограмма

В параллелограмме ABCD ∠A + ∠C = 140°. Найдите ∠B.

Показать решение

Решение. ∠A = ∠C = 70° (противоположные). ∠B = 180° − 70° = 110° (соседний).

Ответ: 110°.

Пример 3. Биссектриса

Биссектриса угла A параллелограмма ABCD пересекает сторону BC в точке K, BK = 15, KC = 9. Найдите периметр.

Показать решение

Решение. △ABK равнобедренный: AB = BK = 15. BC = 15 + 9 = 24. P = 2 · (15 + 24) = 78.

Ответ: 78.

3 Интерактивная практика 25–45 мин

🎯 Тренажёр «Многоугольники и параллелограмм»

Задачи генерируются случайно. Засчитывается при 5 верных из 6.

Блок А. База

П1база

Найдите сумму углов выпуклого двенадцатиугольника.

(12 − 2) · 180° = 1800°.
П2база

Каждый угол правильного многоугольника равен 140°. Сколько у него сторон?

Найдите внешний угол.
Внешний угол 40°, n = 360° : 40° = 9.
П3база

Один из углов параллелограмма равен 47°. Найдите больший угол параллелограмма.

П4база

Периметр параллелограмма равен 48, одна сторона на 3 больше другой. Найдите стороны.

a + b = 24, b = a + 3 → 2a = 21, a = 10,5, b = 13,5.
П5база

Диагонали параллелограмма ABCD пересекаются в точке O, AC = 16, BD = 10, CD = 7. Найдите периметр треугольника COD.

CO = 8, OD = 5, CD = 7: 8 + 5 + 7 = 20.
П6база

Разность двух углов параллелограмма равна 40°. Найдите больший угол.

x + y = 180°, x − y = 40° → x = 110°.

Блок Б. Посложнее

П7средний

Биссектриса угла A параллелограмма ABCD делит сторону BC на отрезки BK = 7 и KC = 14. Найдите периметр параллелограмма.

AB = BK = 7, BC = 21, P = 2 · 28 = 56.
П8средний

Диагональ параллелограмма образует с двумя его сторонами углы 25° и 35°. Найдите углы параллелограмма.

Угол при вершине, из которой выходит диагональ: 25° + 35° = 60°, соседний 120°.
П9средний

Биссектрисы углов A и B параллелограмма ABCD пересекаются в точке M. Найдите угол AMB.

∠A + ∠B = 180°, половины в сумме 90°, тогда ∠AMB = 180° − 90° = 90°.
П10сложнее

Биссектриса тупого угла B параллелограмма ABCD делит сторону AD на отрезки AK : KD = 3 : 4. Периметр параллелограмма 60. Найдите большую сторону.

∠ABK = ∠KBC = ∠AKB.
△ABK равнобедренный: AB = AK = 3x, AD = 7x. P = 2 · 10x = 60 → x = 3, AD = 21.

⭐ Бонусное ДЗ

  1. Докажите, что биссектрисы двух соседних углов параллелограмма перпендикулярны.
    ∠A + ∠B = 180° (односторонние). В треугольнике, образованном биссектрисами и стороной AB, два угла равны ½∠A и ½∠B, их сумма 90°, значит, третий угол 90°.
  2. Внешний угол правильного многоугольника равен 24°. Сколько у него сторон?
    Ответ: 15. 360° : 24° = 15.

★ Бонусная практика

Б1сложнее

Сумма углов выпуклого многоугольника равна 1440°. Сколько у него диагоналей?

(n − 2) · 180° = 1440° → n = 10. Диагоналей 10 · 7 / 2 = 35.
Б2ОГЭ №23

Биссектрисы углов A и D параллелограмма ABCD пересекаются в точке, лежащей на стороне BC. Найдите BC, если AB = 34.

Пусть биссектрисы пересекаются в точке K ∈ BC. △ABK равнобедренный (∠BAK = ∠KAD = ∠BKA): BK = AB = 34. Аналогично △DCK: CK = CD = AB = 34. BC = 34 + 34 = 68.
Б3ОГЭ №24

В параллелограмме ABCD точка E — середина стороны AB. Известно, что EC = ED. Докажите, что данный параллелограмм — прямоугольник.

△EBC = △EAD по трём сторонам: EB = EA, BC = AD, EC = ED. Значит, ∠B = ∠A. Но ∠A + ∠B = 180°, поэтому ∠A = ∠B = 90°, и параллелограмм с прямым углом — прямоугольник.
