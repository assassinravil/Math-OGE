Синус, косинус и тангенс острого угла

Определения в прямоугольном треугольнике, основное тригонометрическое тождество, значения для 30°, 45°, 60°.

① Проверка ДЗ 0–10′ ② Теория 10–25′ ③ Практика 25–45′ ④ ОГЭ 45–55′ ⑤ Итог и ДЗ 55–60′ ★ Бонус

План занятия (60 минут)

  1. 0–10′ Проверка ДЗ занятия 6.
  2. 10–25′ Теория. В лаборатории гипотенуза = 1, поэтому катеты буквально равны sin и cos. Показать 30°, 45°, 60° и сравнить с таблицей.
  3. 25–45′ Тренажёр, затем П1–П8. Ответы можно вводить дробью: 3/5 или 0,6.
  4. 45–55′ ОГЭ №15 — этот тип встречается очень часто.
  5. 55–60′ Шпаргалка, ДЗ. Таблицу значений выучить наизусть.

Типичные ошибки: путают противолежащий и прилежащий катеты; делят гипотенузу на катет (получая число больше 1); забывают, что sin и cos острого угла меньше 1.

2 Теория 10–25 мин

Для острого угла A прямоугольного треугольника (∠C = 90°)
sin A = BC / AB

противолежащий катет / гипотенуза

cos A = AC / AB

прилежащий катет / гипотенуза

tg A = BC / AC

противолежащий / прилежащий

BC = 3, AC = 4, AB = 5 → sin A = 3/5 = 0,6; cos A = 0,8; tg A = 0,75.
Главные формулы
sin²A + cos²A = 1
tg A = sin A / cos A
sin A = cos B,  cos A = sin B (A + B = 90°).
Катеты: BC = AB · sin A, AC = AB · cos A, BC = AC · tg A.
AB = 10, sin A = 0,6 → BC = 6; cos A = √(1 − 0,36) = 0,8.

Пример 1. Найти синус

∠C = 90°, BC = 6, AB = 10. Найдите sin A.

Показать решение

Решение. sin A = BC / AB = 6/10 = 0,6.

Ответ: 0,6.

Пример 2. Найти сторону

∠C = 90°, AB = 35, sin A = 0,4. Найдите BC.

Показать решение

Решение. BC = AB · sin A = 35 · 0,4 = 14.

Ответ: 14.

Пример 3. Тождество

sin A = 0,6 (A — острый). Найдите cos A.

Показать решение

Решение. cos A = √(1 − 0,36) = √0,64 = 0,8.

Ответ: 0,8.

🎯 Тренажёр «Синус, косинус, тангенс»

Ответ можно вводить дробью (3/5) или десятичной (0,6). Засчитывается при 5 верных из 6.

П4база

П5база

В △ABC ∠C = 90°, AC = 7, tg A = 2. Найдите BC.

П6база

Блок Б. Посложнее

П7средний

Угол A острый, sin A = 0,6. Найдите cos A и tg A.

cos A = √(1 − 0,36) = 0,8; tg A = 0,6 / 0,8 = 0,75.
П8средний

Угол A острый, cos A = 5/13. Найдите tg A.

sin A = 12/13, tg A = 12/5 = 2,4.
П9средний

В △ABC ∠C = 90°, ∠A = 30°, AC = 4√3. Найдите BC.

BC = AC · tg 30° = 4√3 · √3/3 = 4.
П10сложнее

В △ABC ∠C = 90°, CH — высота, AC = 10, sin A = 0,8. Найдите CH.

Рассмотрите прямоугольный треугольник ACH.
В △ACH: CH = AC · sin A = 8.

О5ОГЭ №19

Какие из следующих утверждений верны?

  1. Синус острого угла прямоугольного треугольника равен отношению прилежащего катета к гипотенузе.
  2. Тангенс острого угла прямоугольного треугольника равен отношению противолежащего катета к прилежащему.
  3. Для любого острого угла sin²A + cos²A = 1.
1 — неверно: это косинус.

5 Итог и домашнее задание 55–60 мин

Шпаргалка

sin = противолежащий / гипотенуза
cos = прилежащий / гипотенуза
tg = противолежащий / прилежащий
sin² + cos² = 1
30°: ½, √3/2, √3/3
45°: √2/2, √2/2, 1 · 60°: √3/2, ½, √3

⭐ Бонусное ДЗ

  1. В △ABC ∠C = 90°, cos A = 0,6, BC = 8. Найдите AB.
    Ответ: 10. sin A = 0,8 = BC / AB → AB = 10.

    Ответ: 18. Катеты 3x и 4x, гипотенуза 5x = 30 → x = 6, BC = 18.

★ Бонусная практика

Б1сложнее

Б3ОГЭ №24

Докажите, что для любого острого угла A справедливо sin²A + cos²A = 1.

sin²A + cos²A = (BC² + AC²) / AB² = AB² / AB² = 1 по теореме Пифагора.
