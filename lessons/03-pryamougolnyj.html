Прямоугольный треугольник

Острые углы, катет против угла 30°, медиана к гипотенузе, высота из прямого угла.

① Проверка ДЗ 0–10′ ② Теория 10–25′ ③ Практика 25–45′ ④ ОГЭ 45–55′ ⑤ Итог и ДЗ 55–60′ ★ Бонус

План занятия (60 минут)

  1. 0–10′ Проверка ДЗ занятия 2.
  2. 10–25′ Теория. В лаборатории показать: окружность с центром в середине гипотенузы всегда проходит через C — отсюда CM = AB/2. Кнопка «∠A = 30°» — катет BC ровно половина гипотенузы.
  3. 25–45′ Тренажёр (6 раундов, генерируется заново), затем П1–П8; П9–П10 по времени.
  4. 45–55′ ОГЭ №15 и №19.
  5. 55–60′ Шпаргалка, ДЗ.

Типичные ошибки: берут половину гипотенузы как катет против угла 60°; не замечают, что медиана к гипотенузе образует два равнобедренных треугольника; путают, какой угол при высоте равен какому острому углу.

1 Проверка ДЗ 0–10 мин

ДЗ 1

Угол при вершине равнобедренного треугольника равен 56°. Найдите угол при основании.

(180° − 56°) : 2 = 62°.
ДЗ 2

Периметр равнобедренного треугольника 36, боковая сторона 13. Найдите основание.

ДЗ 3

В △ABC AB = BC, ∠A = 65°. Найдите ∠B.

ДЗ 4

В △ABC BM — медиана, AC = 26. Найдите MC.

ДЗ 5№19

1) Медиана делит сторону пополам. 2) Треугольник с углом 60° — равносторонний. 3) Существует треугольник со сторонами 3, 4, 8.

2 Теория 10–25 мин

Элементы ∠C = 90°. AC и BC — катеты, AB — гипотенуза (лежит против прямого угла, самая длинная сторона).
∠A + ∠B = 90°
∠A = 37° → ∠B = 90° − 37° = 53°.
Катет против 30°Равен половине гипотенузы. И обратно: если катет равен половине гипотенузы, противолежащий угол — 30°.
Гипотенуза 18, ∠A = 30° → BC = 9.
Против угла 60° — не половина гипотенузы.
Медиана к гипотенузе (гл. V)Равна половине гипотенузы: CM = AM = MB. Середина гипотенузы — центр описанной окружности.
AB = 13 → CM = 6,5.
Высота из прямого углаCH ⊥ AB. Углы: ∠BCH = ∠A, ∠ACH = ∠B.
∠A = 28° → ∠BCH = 28°, ∠ACH = 62°.
Признаки равенства прямоугольных треугольников
  • по двум катетам;
  • по катету и прилежащему острому углу;
  • по гипотенузе и острому углу;
  • по гипотенузе и катету.

Лаборатория: медиана к гипотенузе и угол 30°

Двигайте точки A и B вдоль катетов.

↳ Разбор примеров

Пример 1

∠C = 90°, ∠B = 30°, AB = 16. Найдите AC.

Показать решение

Решение. AC лежит против ∠B = 30°: AC = 16 : 2 = 8.

Ответ: 8.

Пример 2

∠C = 90°, CM — медиана, ∠B = 35°. Найдите ∠BCM.

Показать решение

Решение. CM = MB, △CMB равнобедренный: ∠BCM = ∠B = 35°.

Ответ: 35.

Пример 3

∠C = 90°, CH — высота, ∠A = 25°. Найдите ∠BCH.

Показать решение

Решение. ∠B = 65°, в △BCH: 90° − 65° = 25°. Короче: ∠BCH = ∠A.

Ответ: 25.

3 Интерактивная практика 25–45 мин

🎯 Тренажёр «Быстрый счёт»

Задачи генерируются случайно. Засчитывается при 5 верных из 6.

Блок А. База

П1база

Один из острых углов прямоугольного треугольника равен 37°. Найдите другой острый угол.

П2база

Гипотенуза прямоугольного треугольника равна 18, один из углов — 30°. Найдите меньший катет.

Меньший катет лежит против меньшего угла — 30°.
18 : 2 = 9.
П3база

Катет, лежащий против угла 30°, равен 7. Найдите гипотенузу.

П4база

Медиана, проведённая к гипотенузе, равна 6,5. Найдите гипотенузу.

П5база

В △ABC ∠C = 90°, CH — высота, ∠A = 28°. Найдите ∠BCH.

∠B = 62°, ∠BCH = 90° − 62° = 28°.
П6база

В △ABC ∠C = 90°, CM — медиана, ∠A = 20°. Найдите ∠ACM.

CM = AM.
△ACM равнобедренный (CM = AM), ∠ACM = ∠A = 20°.

Блок Б. Посложнее

П7средний

Один из острых углов прямоугольного треугольника равен 60°, а сумма гипотенузы и меньшего катета равна 42. Найдите гипотенузу.

Меньший катет лежит против угла 30° и равен c/2.
c + c/2 = 42 → c = 28.
П8средний

Внешний угол при вершине острого угла прямоугольного треугольника равен 150°, гипотенуза — 22. Найдите меньший катет.

Внутренний угол 30°, катет против него 11.
П9средний

В △ABC ∠C = 90°, ∠A = 25°. CH — высота, CM — медиана. Найдите угол MCH.

∠ACM = 25°, ∠ACH = 90° − 25° = 65°. ∠MCH = 65° − 25° = 40°.
П10сложнее

В △ABC ∠C = 90°, ∠A = 32°. CL — биссектриса, CH — высота. Найдите угол LCH.

∠ACL = 45°, ∠ACH = 58°, ∠LCH = 13°.

Какие из следующих утверждений верны?

  1. В прямоугольном треугольнике гипотенуза равна сумме катетов.
  2. Катет прямоугольного треугольника, лежащий против угла 30°, равен половине гипотенузы.
  3. Медиана прямоугольного треугольника, проведённая к гипотенузе, равна половине гипотенузы.

Какие из следующих утверждений верны?

  1. Сумма острых углов прямоугольного треугольника равна 90°.
  2. Гипотенуза прямоугольного треугольника меньше его катета.
  3. Если катет равен половине гипотенузы, то противолежащий ему угол равен 60°.
3 — неверно: угол 30°.

5 Итог и домашнее задание 55–60 мин

Шпаргалка

Острые углы: ∠A + ∠B = 90°
Против 30°: катет = гипотенуза : 2
Медиана к гипотенузе = гипотенуза : 2
Высота CH: ∠BCH = ∠A, ∠ACH = ∠B

📚 Домашнее задание

Ответы проверяются в начале занятия 4.

  1. Один из острых углов прямоугольного треугольника равен 64°. Найдите другой.
    Ответ: 26.
  2. Гипотенуза равна 30, один из острых углов 30°. Найдите меньший катет.
    Ответ: 15.
  3. Медиана, проведённая к гипотенузе, равна 9. Найдите гипотенузу.
    Ответ: 18.
  4. В △ABC ∠C = 90°, CH — высота, ∠B = 55°. Найдите ∠ACH.
    Ответ: 55. ∠ACH = ∠B.
  5. (ОГЭ №19) 1) Если сумма двух углов треугольника равна 90°, то треугольник прямоугольный. 2) Катет, лежащий против угла 60°, равен половине гипотенузы. 3) В прямоугольном треугольнике может быть тупой угол.
    Ответ: 1.

⭐ Бонусное ДЗ

  1. В △ABC ∠C = 90°, ∠A = 30°, AB = 40, CH — высота. Найдите BH.
    Ответ: 10. BC = 20 (против 30°). В △BCH ∠BCH = ∠A = 30°, значит BH = BC : 2 = 10.
  2. Докажите: если медиана треугольника равна половине стороны, к которой она проведена, то треугольник прямоугольный.
    MA = MB = MC. Треугольники AMC и BMC равнобедренные: ∠A = ∠ACM = α, ∠B = ∠BCM = β. Сумма углов: 2α + 2β = 180°, значит ∠C = α + β = 90°.

★ Бонусная практика

Б1сложнее

В △ABC ∠C = 90°, ∠A = 30°, AB = 12, CH — высота. Найдите AH.

BC = 6, ∠BCH = 30°, BH = 3, AH = 12 − 3 = 9.
Б2сложнее

Высота прямоугольного треугольника, проведённая из вершины прямого угла, делит его на два угла, один из которых на 40° больше другого. Найдите больший острый угол треугольника.

Части прямого угла: 25° и 65°. Они равны острым углам треугольника, больший 65°.
Б3сложнее

В прямоугольном треугольнике угол между высотой и медианой, проведёнными из вершины прямого угла, равен 20°. Найдите больший острый угол треугольника.

Угол между ними |90° − 2∠A| = 20°, ∠A = 35° или 55°. Больший острый угол 55°.
