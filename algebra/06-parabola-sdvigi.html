Функция y = ax² и сдвиги графика

Как коэффициент a меняет параболу, графики y = ax² + n и y = a(x − m)², вершина параболы.

Типичные ошибки: сдвиг y = (x + m)² делают вправо; путают вершину (m; n) со знаками в формуле; считают, что при |a| > 1 парабола шире.

2 Теория 10–25 мин

y = ax² Вершина (0; 0), ось симметрии — Oy.
a > 0 — ветви вверх, a < 0 — вниз.
|a| > 1 — парабола уже (растяжение), |a| < 1 — шире (сжатие).
y = −3x²: ветви вниз, уже, чем y = x².
y = 0,5x²: ветви вверх, шире.
Сдвиги графика
  • y = ax² + n — сдвиг на n вверх (n < 0 — вниз).
  • y = a(x − m)² — сдвиг на m вправо (m < 0 — влево).
y = a(x − m)² + n → вершина (m; n)
y = (x − 1)² + 4 → вершина (1; 4): вправо на 1, вверх на 4.
y = (x + 3)² − 2 → вершина (−3; −2): «плюс» в скобке — сдвиг влево.

Лаборатория: a, m, n

1 0 0

Серым — исходная парабола y = x².

↳ Разбор примеров

Пример 1. Вершина

Найдите вершину параболы y = −2(x + 3)² − 5.

Показать решение

Решение. m = −3, n = −5.

Ответ: (−3; −5).

Пример 2. Найти a

График y = ax² проходит через (−2; −8). Найдите a.

Показать решение

Решение. −8 = a · 4 → a = −2.

Ответ: −2.

Пример 3. Нули

Нули функции y = (x − 1)² − 4.

Показать решение

Решение. (x − 1)² = 4 → x − 1 = ±2 → x = −1 и 3.

Ответ: −1; 3.
