1 Теория 0–20 мин

Функция Зависимость y от x, при которой каждому x соответствует ровно одно y. Запись: y = f(x).
  • D(f) — область определения: все допустимые x.
  • E(f) — множество значений: все получающиеся y.
f(x) = 2x − 1. Тогда f(3) = 2 · 3 − 1 = 5.
Область определения по формуле
  • Знаменатель не равен нулю.
  • Выражение под корнем ≥ 0.
  • Многочлен — x любое.
y = 7/(x + 3): x + 3 ≠ 0 → x ≠ −3.
y = √(x − 4): x − 4 ≥ 0 → x ≥ 4.
y = x² − 5x: ограничений нет → x — любое.
НулиЗначения x, при которых f(x) = 0 — точки пересечения графика с осью Ox.
y = 2x − 6: 2x − 6 = 0 → x = 3.
Знакиf(x) > 0 — график выше оси Ox,
f(x) < 0 — ниже.
y = 2x − 6: y > 0 при x > 3, y < 0 при x < 3.
МонотонностьВозрастает: больше x → больше y (график идёт вверх слева направо). Убывает — наоборот.
y = x² убывает на (−∞; 0], возрастает на [0; +∞).
Чётная функция1) D(f) симметрична относительно нуля; 2) f(−x) = f(x). График симметричен относительно оси Oy.
f(x) = x²: f(−x) = (−x)² = x² = f(x) → чётная.
Нечётная функция1) D(f) симметрична относительно нуля; 2) f(−x) = −f(x). График симметричен относительно начала координат.
f(x) = x³: f(−x) = −x³ = −f(x) → нечётная.
y = √x — ни чётная, ни нечётная: D = [0; +∞) не симметрична.

↳ Разбор примеров

Пример 1. Значение

f(x) = 3x² − 2x. Найдите f(−2).

Показать решение

Решение. 3 · 4 − 2 · (−2) = 12 + 4 = 16.

Ответ: 16.

Пример 2. Область определения

Найдите D(y), если y = √(6 − 2x).

Показать решение

Решение. 6 − 2x ≥ 0 → x ≤ 3.

Ответ: x ≤ 3.

Пример 3. Чётность

f(x) = x⁴ − 3x². Чётная ли она?

Показать решение

Решение. f(−x) = x⁴ − 3x² = f(x) — чётная.

Ответ: чётная.

4 Итог и домашнее задание 55–60 мин

Шпаргалка

D(f): знаменатель ≠ 0, под корнем ≥ 0
Нули: f(x) = 0
Чётная: D(f) симметрична и f(−x) = f(x)
Нечётная: f(−x) = −f(x), симметрия O
Возрастание читается по x слева направо
