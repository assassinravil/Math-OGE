2 Теория 10–25 мин

Главное о параболе y = ax² + bx + c
x₀ = −b / (2a),   y₀ = −(b² − 4ac) / (4a)
Формулы получаются выделением полного квадрата: ax² + bx + c = a(x − x₀)² + y₀. На практике y₀ проще найти подстановкой x₀.
Ось симметрии — прямая x = x₀.
Пересечение с Oy — точка (0; c).
Нули — корни ax² + bx + c = 0: при D > 0 — два, D = 0 — один (вершина на оси), D < 0 — нет.
y = x² − 4x + 3: x₀ = 4/2 = 2, y₀ = 4 − 8 + 3 = −1 → вершина (2; −1); с Oy — (0; 3); нули 1 и 3.
Алгоритм построения
  1. Направление ветвей по знаку a.
  2. Вершина (x₀; y₀) и ось симметрии.
  3. Точка (0; c) и симметричная ей.
  4. Нули (если есть).
  5. Провести плавную кривую.
y = x² − 4x + 3: точка (0; 3) симметрична точке (4; 3) относительно x = 2.
Знаки коэффициентов по графику (№11) a: ветви вверх → a > 0.
c: где парабола пересекает Oy — выше нуля → c > 0.
D: число точек пересечения с Ox.
b: x₀ = −b/(2a) — знак b противоположен знаку a·x₀.
Ветви вверх (a > 0), вершина справа от Oy (x₀ > 0) → b < 0.
Свойства (a > 0) Убывает на (−∞; x₀], возрастает на [x₀; +∞).
Наименьшее значение y₀, E(y) = [y₀; +∞).
При a < 0 — наоборот, наибольшее значение y₀.
y = x² − 4x + 3: убывает на (−∞; 2], возрастает на [2; +∞), E = [−1; +∞).

Лаборатория: a, b, c

1 −2 −3

↳ Разбор примеров

Пример 1. Вершина

y = x² − 6x + 5. Найдите вершину.

Показать решение

Решение. x₀ = 6/2 = 3, y₀ = 9 − 18 + 5 = −4.

Ответ: (3; −4).

Пример 2. Наибольшее значение

y = −x² + 4x + 1. Найдите наибольшее значение.

Показать решение

Решение. x₀ = −4/(−2) = 2, y₀ = −4 + 8 + 1 = 5.

Ответ: 5.

Пример 3. Найти b

Ось симметрии параболы y = x² + bx + 1 — прямая x = 3. Найдите b.

Показать решение

Решение. −b/2 = 3 → b = −6.

Ответ: −6.

О4ОГЭ №19

Какие утверждения верны?

  1. Если a > 0, ветви параболы y = ax² + bx + c направлены вверх.
  2. График функции y = x² + 2x + 5 пересекает ось Ox.
  3. График функции y = ax² + bx + c пересекает ось Oy в точке (0; c).
2 — неверно: D = 4 − 20 < 0.

⭐ Бонусное ДЗ

  1. При каком c парабола y = x² + 4x + c касается оси Ox?
    Ответ: 4. D = 16 − 4c = 0.
