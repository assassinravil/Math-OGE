2 Теория 10–25 мин

Сравнение дробей
  • Приводим к общему знаменателю — больше та, у которой больше числитель.
  • Или переводим обе в десятичные дроби.
5/6 и 7/9: 15/18 > 14/18, значит 5/6 > 7/9.
5/6 и 0,83: 5/6 = 0,833… > 0,83.
Отрицательные числа
  • Любое отрицательное число меньше положительного и нуля.
  • Из двух отрицательных больше то, у которого модуль меньше.
−250 > −350, так как 250 < 350.
−4,9 < −4,25: модуль 4,9 больше.
Корни
  • Если 0 ≤ a < b, то √a < √b.
  • Число представляем как корень: 7 = √49.
  • Множитель вносим под корень: 2√3 = √(4 · 3) = √12.
7 и √48: 7 = √49 > √48.
√30: 25 < 30 < 36, значит 5 < √30 < 6.
3√5 = √45 и 2√11 = √44 → 3√5 > 2√11.
Координатная прямая (№7)
  • Правее — больше.
  • Расстояние до нуля — модуль числа.
  • Для оценки подставьте конкретное число из промежутка.
−1 < a < 0, например a = −0,5: a² = 0,25, 1/a = −2. Значит 1/a < a < a².
a² не всегда больше a: при a = 0,5 a² = 0,25 < a.
Погрешность приближения
  • Абсолютная погрешность — модуль разности точного и приближённого значений: |x − a|.
  • Запись x = a ± h означает a − h ≤ x ≤ a + h (точность h).
  • Относительная погрешность — h : |a|, обычно в процентах.
2,25 ≈ 2,3: погрешность |2,25 − 2,3| = 0,05.
l = 18 ± 0,3 м → 17,7 ≤ l ≤ 18,3.
b = 0,4 ± 0,1 см: относительная погрешность 0,1 : 0,4 = 25%.

Лаборатория: где a², 1/a, −a?

Перетаскивайте точку a.

↳ Разбор примеров

Пример 1. Дробь и десятичная

Сравните 5/6 и 0,83.

Показать решение

Решение. 5/6 = 0,8333… Сравниваем поразрядно: 0,833… > 0,830.

Ответ: 5/6 > 0,83.

Пример 2. Оценка корня

Между какими соседними целыми числами лежит √57?

Показать решение

Решение. 7² = 49 < 57 < 64 = 8², значит 7 < √57 < 8.

Ответ: 7 и 8.

Пример 3. №7

Число a лежит между −1 и 0. Какое из чисел a, a², 1/a наибольшее?

Показать решение

Решение. Возьмём a = −0,5: a² = 0,25, 1/a = −2. Положительное только a².

Ответ: a².

Шпаргалка

отрицательные: больше то, у которого модуль меньше
k < √n < k + 1 ⇔ k² < n < (k + 1)²
a√b = √(a²b)
на прямой: подставь конкретное число
x = a ± h ⇔ a − h ≤ x ≤ a + h
