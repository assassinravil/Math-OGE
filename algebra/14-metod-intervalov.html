2 Теория 10–25 мин

Алгоритм метода интервалов
  1. Перенести всё в левую часть, справа 0. Разложить на множители вида (x − a).
  2. Отметить нули на прямой.
  3. В крайнем правом промежутке знак «+» (все множители положительны), дальше знаки чередуются.
  4. Выбрать промежутки с нужным знаком.
(x + 3)(x − 1)(x − 4) > 0. Нули −3, 1, 4.
Ответ: (−3; 1) ∪ (4; +∞).
(x + 1)(3 − x) ≥ 0. Сначала (3 − x) = −(x − 3): (x + 1)(x − 3) ≤ 0 → [−1; 3]. Знак неравенства поменялся!
Кратные корни
  • Множитель в чётной степени (x − a)²: при переходе через a знак не меняется.
  • В нечётной степени — меняется, как обычно.
(x − 2)²(x + 1) > 0. Нули −1 и 2 (кратности 2).
Ответ: (−1; 2) ∪ (2; +∞).
(x − 2)²(x + 1) ≤ 0 → (−∞; −1] ∪ {2}. Изолированную точку x = 2 не терять!
Дробные неравенства
знак P(x)/Q(x) = знак P(x)·Q(x)
  • Нули знаменателя всегда выколоты, даже в нестрогом неравенстве.
  • Умножать на знаменатель нельзя — его знак неизвестен.
(x − 3)/(x + 2) ≤ 0. Нули 3 (числитель) и −2 (знаменатель).
Ответ: (−2; 3].
Как оформлять №20 №20
  1. Привести к виду «произведение (частное) сравнивается с 0».
  2. Нарисовать прямую с нулями и знаками.
  3. Записать ответ промежутками, проверить концы.
x²(−x² − 64) ≤ 64(−x² − 64) → (x² − 64)(−x² − 64) ≤ 0 → −(x² + 64)(x² − 64) ≤ 0 → x² − 64 ≥ 0, так как x² + 64 > 0.
Ответ: (−∞; −8] ∪ [8; +∞).

Лаборатория: знаки и интервалы

−3 1 4

Кривая показывает только знак выражения (масштаб сжат). Зелёным на оси — решения.

↳ Разбор примеров

Пример 1. Три множителя

Решите неравенство (x + 3)(x − 1)(x − 4) ≥ 0.

Показать решение

Решение. Нули −3, 1, 4. Знаки справа налево: +, −, +, −. Точки закрашены.

Ответ: [−3; 1] ∪ [4; +∞).

Пример 2. Кратный корень

Решите неравенство (x − 2)²(x + 1) ≤ 0.

Показать решение

Решение. Знаки: (−∞; −1) «−», (−1; 2) «+», (2; +∞) «+» — через 2 знак не меняется. Нужен «−» и нули.

Ответ: (−∞; −1] ∪ {2}.

Пример 3. Дробь

Решите неравенство (x + 2)/(x − 3) ≤ 0.

Показать решение

Решение. Нули −2 (числитель, закрашен) и 3 (знаменатель, выколот). «−» между ними.

Ответ: [−2; 3).

3 Интерактивная практика 25–45 мин

🎯 Тренажёр «Метод интервалов»

Задачи генерируются случайно. Засчитывается при 5 верных из 6.

Блок А. База

П1база

Найдите наибольшее целое решение неравенства (x + 3)(x − 1)(x − 5) < 0.

(−∞; −3) ∪ (1; 5).
П2база

Найдите наименьшее целое решение неравенства (x + 2)(x − 3)(x − 6) ≥ 0.

[−2; 3] ∪ [6; +∞).
П3база

Сколько целых решений имеет неравенство (x − 4)/(x + 1) ≤ 0?

(−1; 4]: 0, 1, 2, 3, 4.
П4база

Найдите наибольшее целое решение неравенства (x − 3)²(x + 2) < 0.

x < −2 (через 3 знак не меняется, а x = 3 не подходит: 0 < 0 — неверно).
П5база

Сколько целых решений имеет неравенство (x + 5)(2 − x) > 0?

(x + 5)(x − 2) < 0 → (−5; 2).
П6база

Найдите наименьшее натуральное решение неравенства (x + 1)/(x − 2) > 0.

(−∞; −1) ∪ (2; +∞).

Блок Б. Посложнее

П7средний

Найдите наибольшее целое решение неравенства (x − 1)(x − 3)² ≤ 0.

Не потеряйте изолированную точку.
(−∞; 1] ∪ {3}.
П8средний

Сколько целых решений неравенства (x² − 9)/(x − 1) ≥ 0 принадлежат отрезку [−5; 5]?

[−3; 1) ∪ [3; +∞): −3, −2, −1, 0, 3, 4, 5.
П9средний

Сколько целых решений имеет неравенство x⁴ − 10x² + 9 ≤ 0?

(x² − 1)(x² − 9) ≤ 0 → 1 ≤ x² ≤ 9 → [−3; −1] ∪ [1; 3].
П10сложнее

Сколько целых решений имеет неравенство (x² − 4x + 3)/(x² − 4) ≤ 0?

(x − 1)(x − 3)/((x − 2)(x + 2)) ≤ 0 → (−2; 1] ∪ (2; 3]: −1, 0, 1, 3.

О4ОГЭ №20

Решите неравенство x²(−x² − 64) ≤ 64(−x² − 64). Сколько целых чисел не являются его решениями?

−(x² + 64)(x² − 64) ≤ 0 → x² ≥ 64 → (−∞; −8] ∪ [8; +∞). Не решения: от −7 до 7 — 15 чисел.
О5ОГЭ №19

Какие утверждения верны?

  1. Если в разложении есть множитель (x − a)², то при переходе через a знак выражения не меняется.
  2. В нестрогом дробном неравенстве нули знаменателя включаются в ответ.
  3. Неравенство (x − 1)/(x + 2) > 0 равносильно неравенству (x − 1)(x + 2) > 0.
2 — неверно: нули знаменателя всегда выколоты.
