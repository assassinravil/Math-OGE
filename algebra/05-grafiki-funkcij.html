2 Теория 10–25 мин

y = kx + b — прямаяk > 0 — возрастает, k < 0 — убывает.
b — точка пересечения с Oy: (0; b).
Одинаковые k — прямые параллельны.
y = −2x + 3: убывает, пересекает Oy в (0; 3).
y = k/x — гиперболаk > 0 — I и III четверти,
k < 0 — II и IV четверти.
x ≠ 0, оси не пересекает.
y = −6/x: II и IV четверти; при x = 2 y = −3.
y = x² — параболаВершина (0; 0), ветви вверх.
Чётная, E(y) = [0; +∞).
x = −3 → y = 9.
y = x³ — кубическая параболаНечётная, возрастает на всей прямой.
x = −2 → y = −8.
y = √xx ≥ 0, y ≥ 0. Половина параболы, «лежащей на боку».
x = 9 → y = 3; x = −4 — нельзя.
y = |x|Галочка с вершиной (0; 0). Чётная.
|−5| = 5, |5| = 5.
Схема описания свойств функции (как в учебнике)
  1. область определения D(f);
  2. множество значений E(f);
  3. нули;
  4. промежутки знакопостоянства;
  5. промежутки монотонности;
  6. наибольшее и наименьшее значения;
  7. чётность или нечётность.
y = x²: D = все x; E = [0; +∞); нуль x = 0; y > 0 при x ≠ 0; убывает на (−∞; 0], возрастает на [0; +∞); наименьшее 0, наибольшего нет; чётная.

↳ Разбор примеров

Пример 1. Найти k

График y = kx проходит через A(3; −12). Найдите k.

Показать решение

Решение. −12 = 3k → k = −4.

Ответ: −4.

Пример 2. Гипербола

График y = k/x проходит через (2; −5). Найдите k.

Показать решение

Решение. k = x · y = −10.

Ответ: −10.

Пример 3. Пересечение

Найдите точку пересечения y = 2x + 3 и y = −x + 9.

Показать решение

Решение. 2x + 3 = −x + 9 → x = 2, y = 7.

Ответ: (2; 7).

П10сложнее

Какие утверждения верны?

  1. График функции y = kx + b при k > 0 — возрастающая прямая.
  2. График функции y = k/x при k < 0 расположен в I и III четвертях.
  3. Графики функций y = 2x + 1 и y = 2x − 3 параллельны.
