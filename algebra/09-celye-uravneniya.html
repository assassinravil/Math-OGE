Целые уравнения: разложение, замена, биквадратные

Степень уравнения, разложение на множители (вынесение, группировка), замена переменной, биквадратные уравнения. ОГЭ №9 и №20.

① Проверка ДЗ 0–10′ ② Теория 10–25′ ③ Практика 25–45′ ④ ОГЭ 45–55′ ⑤ Итог и ДЗ 55–60′ ★ Бонус

План занятия (60 минут)

  1. 0–10′ Проверка ДЗ занятия 8.
  2. 10–25′ Теория: степень уравнения, три приёма. Главная ловушка: нельзя делить на x. В лаборатории подобрать b и c, при которых у биквадратного уравнения 4, 2 и 0 корней.
  3. 25–45′ Тренажёр, затем П1–П10.
  4. 45–55′ ОГЭ №9 и №20: оформить решение №20 письменно.
  5. 55–60′ Шпаргалка, ДЗ.

Типичные ошибки: делят обе части на x (или на x − a) и теряют корень; в биквадратном уравнении не отбрасывают t < 0 или забывают второй корень x = −√t; после замены не возвращаются к x.

2 Теория 10–25 мин

Целое уравнение и его степень
  • Обе части — целые выражения (нет деления на выражение с переменной).
  • Переносим всё в левую часть и упрощаем: P(x) = 0. Степень уравнения — степень многочлена P(x).
  • Уравнение n-й степени имеет не более n корней.
(x − 2)(x + 3) = x² + 1 → x² + x − 6 = x² + 1 → x − 7 = 0. Уравнение первой степени, x = 7.
x³ = 4x. Делить на x нельзя — потеряется корень 0. Правильно: x³ − 4x = 0 → x(x − 2)(x + 2) = 0 → 0; ±2.
Разложение на множители
A · B = 0 ⇔ A = 0 или B = 0
  1. Перенести всё в одну часть.
  2. Разложить: вынести общий множитель, сгруппировать, применить формулы.
  3. Приравнять к нулю каждый множитель.
Вынесение: x³ − 9x = 0 → x(x − 3)(x + 3) = 0 → x = 0; ±3.
Группировка: x³ + 2x² − 9x − 18 = 0 → x²(x + 2) − 9(x + 2) = 0 → (x + 2)(x − 3)(x + 3) = 0 → x = −3; −2; 3.
Замена переменной Одно и то же выражение повторяется → обозначаем его буквой t, решаем, возвращаемся к x.
(x² + x)² − 8(x² + x) + 12 = 0. Пусть t = x² + x: t² − 8t + 12 = 0 → t = 2 или t = 6.
x² + x = 2 → x = 1; −2.   x² + x = 6 → x = 2; −3.
Ответ: −3; −2; 1; 2.
Биквадратное уравнение
ax⁴ + bx² + c = 0,   t = x², t ≥ 0
x⁴ − 5x² + 4 = 0 → t² − 5t + 4 = 0 → t = 1; 4 → x = ±1; ±2 (четыре корня).
x⁴ + 3x² − 4 = 0 → t = 1 или t = −4. x² = −4 корней не имеет → x = ±1.

Лаборатория: сколько корней у x⁴ + bx² + c = 0

−5 4

Корни уравнения — точки пересечения графика y = x⁴ + bx² + c с осью Ox. Каждому t > 0 соответствуют два корня ±√t, t = 0 — один корень, t < 0 — ни одного.

↳ Разбор примеров

Пример 1. Вынесение множителя

Решите уравнение 2x³ − 8x = 0.

Показать решение

Решение. 2x(x² − 4) = 0 → 2x(x − 2)(x + 2) = 0 → x = 0, x = 2, x = −2.

Ответ: −2; 0; 2.

Пример 2. Биквадратное

Решите уравнение x⁴ − 10x² + 9 = 0.

Показать решение

Решение. t = x² ≥ 0: t² − 10t + 9 = 0 → t = 1 или t = 9. x² = 1 → x = ±1; x² = 9 → x = ±3.

Ответ: −3; −1; 1; 3.

Пример 3. Замена

Решите уравнение (x² + 2x)² − 2(x² + 2x) − 3 = 0.

Показать решение

Решение. t = x² + 2x: t² − 2t − 3 = 0 → t = 3 или t = −1.
x² + 2x − 3 = 0 → x = 1; −3.
x² + 2x + 1 = 0 → x = −1.

Ответ: −3; −1; 1.

3 Интерактивная практика 25–45 мин

🎯 Тренажёр «Целые уравнения»

Задачи генерируются случайно. Засчитывается при 5 верных из 6.

Блок А. База

П1база

Решите уравнение x³ − 16x = 0. Корни запишите в порядке возрастания.

П2база

Решите уравнение x⁴ − 13x² + 36 = 0. В ответе укажите наибольший корень.

П3база

Найдите сумму корней уравнения (x − 5)(x² − 4) = 0.

Корни 5, 2, −2.
П4база

Решите уравнение x⁴ + 2x² − 3 = 0.

t = 1 или t = −3 (не подходит).
П5база

Найдите степень уравнения (x² − 1)(x³ + 2) = x⁵ + 3.

x⁵ − x³ + 2x² − 2 = x⁵ + 3 → −x³ + 2x² − 5 = 0.
П6база

Решите уравнение x³ + 3x² − 4x − 12 = 0. Корни запишите в порядке возрастания.

Сгруппируйте первые два и последние два слагаемых.
x²(x + 3) − 4(x + 3) = (x + 3)(x − 2)(x + 2).

Блок Б. Посложнее

П7средний

Решите уравнение x⁴ − 5x² − 36 = 0.

t = 9 или t = −4 (не подходит).
П8средний

Решите уравнение x³ − 2x² − x + 2 = 0. Корни запишите в порядке возрастания.

x²(x − 2) − (x − 2) = (x − 2)(x − 1)(x + 1).
П9средний

Решите уравнение (x² − 2x)² − 2(x² − 2x) − 3 = 0. Корни запишите в порядке возрастания.

t = x² − 2x: t = 3 или t = −1. x² − 2x = 3 → −1; 3. x² − 2x = −1 → x = 1.
П10сложнее

Решите уравнение (x² + 3x)² − 2(x² + 3x) = 8. Корни запишите в порядке возрастания.

t² − 2t − 8 = 0 → t = 4 или t = −2. x² + 3x = 4 → 1; −4. x² + 3x = −2 → −1; −2.

4 Задачи в формате ОГЭ 45–55 мин

О1ОГЭ №9

Решите уравнение (5x − 2)(−x + 3) = 0. Если уравнение имеет более одного корня, в ответ запишите меньший из корней.

О2ОГЭ №20

Решите уравнение x⁴ = (x − 6)².

x² = x − 6 (D < 0, корней нет) или x² = −(x − 6) → x² + x − 6 = 0 → x = −3; 2.
О3ОГЭ №20

Решите уравнение x³ + 5x² − 4x − 20 = 0. Корни запишите в порядке возрастания.

x²(x + 5) − 4(x + 5) = 0 → (x + 5)(x − 2)(x + 2) = 0.
О4ОГЭ №20

Решите уравнение (x² − 25)² + (x² + 3x − 10)² = 0.

Сумма квадратов равна 0, только если оба выражения равны 0. x² − 25 = 0 → ±5; x² + 3x − 10 = 0 → 2; −5. Общий корень −5.
О5ОГЭ №19

Какие утверждения верны?

  1. Уравнение x⁴ + 1 = 0 не имеет корней.
  2. Уравнение третьей степени всегда имеет три корня.
  3. Уравнение x(x − 1)(x + 2) = 0 имеет три корня.
2 — неверно: например, x³ = 0 имеет один корень.

5 Итог и домашнее задание 55–60 мин

Шпаргалка

Всё влево → разложить → каждый множитель = 0
Делить на x нельзя — теряется корень 0
Биквадратное: t = x², t ≥ 0, x = ±√t
Замена: повторяется выражение → t, потом вернуться к x
Степень n — не более n корней

⭐ Бонусное ДЗ

  1. Решите уравнение (x² − 4x)² + 9(x² − 4x) + 20 = 0.
    Ответ: 2. t = −4 или t = −5. x² − 4x + 4 = 0 → x = 2; x² − 4x + 5 = 0 — корней нет.
  2. Решите уравнение x⁴ = (2x − 3)².
    Ответ: −3; 1. x² = 2x − 3 (корней нет) или x² = 3 − 2x → x = 1; −3.

★ Бонусная практика

Б1сложнее

Решите уравнение x⁴ = (3x − 10)².

x² = 3x − 10 — D < 0; x² = 10 − 3x → x = 2; −5.
Б2сложнее

Решите уравнение (x − 1)(x − 2)(x − 3)(x − 4) = 24.

Перемножьте первую скобку с четвёртой, вторую с третьей.
(x² − 5x + 4)(x² − 5x + 6) = 24, t = x² − 5x: (t + 4)(t + 6) = 24 → t² + 10t = 0 → t = 0 или t = −10. x² − 5x = 0 → 0; 5. x² − 5x + 10 = 0 — корней нет.
Б3сложнее

Сколько корней имеет уравнение x⁴ − 5x² + 6 = 0?

t = 2 или t = 3, оба положительны → x = ±√2, ±√3.
