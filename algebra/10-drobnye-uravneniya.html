Дробные рациональные уравнения

Допустимые значения переменной, умножение на общий знаменатель, отбор корней. Главная ловушка — корень, обращающий знаменатель в нуль.

2 Теория 10–25 мин

Дробное рациональное уравнение
  • Есть деление на выражение с переменной.
  • Допустимые значения: все знаменатели ≠ 0. Их выписывают до решения.
3/(x − 2) + 1/x = 1 → x ≠ 2, x ≠ 0.
5/(x² − 9) = 1 → x² ≠ 9 → x ≠ ±3.
Дробь равна нулю
A / B = 0 ⇔ A = 0 и B ≠ 0
(x² − 5x + 6)/(x − 3) = 0 → x² − 5x + 6 = 0 → x = 2 или x = 3. При x = 3 знаменатель 0 → ответ: 2.
(x² − 4)/(x − 2) = 0 → x = ±2, но x = 2 посторонний. Ответ: −2 (один корень, а не два).
Алгоритм решения
  1. Найти общий знаменатель, записать условие «≠ 0».
  2. Умножить обе части на общий знаменатель (каждое слагаемое).
  3. Решить получившееся целое уравнение.
  4. Исключить корни, обращающие знаменатель в нуль.
x/(x + 2) = 4/(x + 6). Общий знаменатель (x + 2)(x + 6), x ≠ −2, x ≠ −6.
x(x + 6) = 4(x + 2) → x² + 2x − 8 = 0 → x = 2; −4. Оба допустимы.
x/(x − 2) − 1/(x + 2) = 8/(x² − 4). Умножаем на x² − 4: x(x + 2) − (x − 2) = 8 → x² + x − 6 = 0 → x = 2; −3. x = 2 обращает знаменатель в 0. Ответ: −3.
Замена в дробных уравнениях Выражение 1/x (или x + 1/x) повторяется → вводим t.
1/x² + 3/x − 10 = 0. t = 1/x: t² + 3t − 10 = 0 → t = 2 или t = −5 → x = 0,5 или x = −0,2.
Пропорция: A/B = C/D → A·D = B·C (при B ≠ 0, D ≠ 0).
(x + 3)/(x − 1) = 2 → x + 3 = 2x − 2 → x = 5.

↳ Разбор примеров

Пример 1. Дробь = 0

Решите уравнение (x² + 2x)/(x + 2) = 0.

Показать решение

Решение. x(x + 2) = 0 → x = 0 или x = −2. При x = −2 знаменатель равен 0.

Ответ: 0.

Пример 2. Общий знаменатель

Решите уравнение (x + 3)/(x − 3) + (x − 3)/(x + 3) = 10/3.

Показать решение

Решение. x ≠ ±3. Умножим на 3(x² − 9): 3(x + 3)² + 3(x − 3)² = 10(x² − 9) → 6x² + 54 = 10x² − 90 → x² = 36 → x = ±6.

Ответ: −6; 6.

Пример 3. Посторонний корень

Решите уравнение 2/(x − 1) = (x + 1)/(x − 1).

Показать решение

Решение. x ≠ 1. 2 = x + 1 → x = 1 — обращает знаменатель в 0.

Ответ: корней нет.

3 Интерактивная практика 25–45 мин

🎯 Тренажёр «Дробные уравнения»

Задачи генерируются случайно. Засчитывается при 5 верных из 6.

Блок А. База

П1база

Решите уравнение 6/(x − 2) = 3.

П2база

Решите уравнение (x² − 9)/(x + 3) = 0.

П3база

Решите уравнение (x² − 5x + 6)/(x − 2) = 0.

x = 2 — посторонний.
П4база

Решите уравнение x/(x + 2) = 4/(x + 6).

П5база

Решите уравнение (x + 3)/(x − 1) = 2.

П6база

Решите уравнение (x² + 2x)/(x + 2) = 0.

Блок Б. Посложнее

П7средний

Решите уравнение 1/x² + 3/x − 10 = 0.

t = 1/x: t = 2 или t = −5.
П8средний

Сколько корней имеет уравнение x/(x − 2) − 8/(x² − 4) = 1?

x ≠ ±2. x(x + 2) − 8 = x² − 4 → 2x = 4 → x = 2 — посторонний. Корней нет.
П9средний

Решите уравнение x²/(x − 3) = 9/(x − 3).

x² = 9, x ≠ 3 → x = −3.
П10сложнее

Решите уравнение 1/(x − 1) + 1/(x + 1) = 4/3.

2x/(x² − 1) = 4/3 → 6x = 4x² − 4 → 2x² − 3x − 2 = 0 → x = 2; −0,5.

4 Задачи в формате ОГЭ 45–55 мин

О1ОГЭ №9

Найдите корень уравнения 4/(x − 7) = −2.

О2ОГЭ №20

Решите уравнение x/(x − 2) − 1/(x + 2) = 8/(x² − 4).

x ≠ ±2. x(x + 2) − (x − 2) = 8 → x² + x − 6 = 0 → x = 2 (посторонний) или x = −3.
О3ОГЭ №20

Решите уравнение x² − 2x + √(3 − x) = √(3 − x) + 8.

Условие 3 − x ≥ 0, то есть x ≤ 3. x² − 2x − 8 = 0 → x = 4 (не подходит) или x = −2.
О4ОГЭ №20

Решите уравнение 2/x² − 1/x − 1 = 0.

t = 1/x: 2t² − t − 1 = 0 → t = 1 или t = −0,5 → x = 1 или x = −2.
О5ОГЭ №19

Какие утверждения верны?

  1. Дробь равна нулю, если её числитель равен нулю, а знаменатель не равен нулю.
  2. Уравнение (x² − 1)/(x − 1) = 0 имеет два корня.
  3. При умножении обеих частей дробного уравнения на общий знаменатель могут появиться посторонние корни.
2 — неверно: x = 1 посторонний, корень один.

    Ответ: 0,5; 4. x ≠ 0, 2. 3x + 2(x − 2) = 2x(x − 2) → 2x² − 9x + 4 = 0 → x = 4 или x = 0,5.

★ Бонусная практика

Б1сложнее

Решите уравнение (x² + 1/x²) − 3(x + 1/x) + 4 = 0. Сколько корней?

t = x + 1/x, x² + 1/x² = t² − 2: t² − 3t + 2 = 0 → t = 1 (x + 1/x = 1 — корней нет) или t = 2 → x = 1.
Б2сложнее

Сколько корней имеет уравнение 1/(x − 2) + 1/(x − 3) = 1/((x − 2)(x − 3))?

x ≠ 2, 3. (x − 3) + (x − 2) = 1 → x = 3 — посторонний.
Б3сложнее

При каком a уравнение (x − a)/(x − 3) = 0 не имеет корней?

Единственный кандидат x = a; он посторонний при a = 3.
