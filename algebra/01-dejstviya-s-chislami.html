1 Теория 0–20 мин

Числовые множества
  • N — натуральные: 1, 2, 3, …
  • Z — целые: натуральные, противоположные им и 0.
  • Q — рациональные: числа вида m/n, m ∈ Z, n ∈ N.
  • R — действительные: рациональные и иррациональные.
N ⊂ Z ⊂ Q ⊂ R
−20 ∈ Z, но −20 ∉ N.   1,2 ∈ Q, но 1,2 ∉ Z.
Рациональное или иррациональное
  • Рациональное число — конечная или бесконечная периодическая десятичная дробь.
  • Иррациональное — бесконечная непериодическая дробь.
  • √n иррационален, если n — не квадрат натурального числа.
1/3 = 0,333… = 0,(3);   5/6 = 0,8(3) — рациональные.
√3, √5, √10, π — иррациональные.
√16 = 4 и √0,25 = 0,5 — рациональные: корень извлекается.
Порядок действий
  1. Действия в скобках.
  2. Степени.
  3. Умножение и деление слева направо.
  4. Сложение и вычитание слева направо.
20 − 4 · 3² = 20 − 4 · 9 = 20 − 36 = −16.
−3² = −9 (в квадрат возводится только 3), а (−3)² = 9.
Обыкновенные дроби
  • Сложение и вычитание — через общий знаменатель.
  • Умножение — числитель на числитель, знаменатель на знаменатель.
  • Деление — умножение на обратную дробь.
2/3 + 3/4 = 8/12 + 9/12 = 17/12.
3/4 : 9/8 = 3/4 · 8/9 = 2/3.
Десятичные дроби
  • Делим на десятичную дробь: переносим запятую в обоих числах так, чтобы делитель стал целым.
  • Смешанное число → неправильная дробь: 1 2/3 = 5/3.
2,4 : 0,06 = 240 : 6 = 40.
1 2/3 · 0,6 = 5/3 · 3/5 = 1.
Законы — упрощают счёт
  • a + b = b + a,   ab = ba;
  • (ab)c = a(bc);
  • a(b + c) = ab + ac.
17 · 0,25 · 4 = 17 · 1 = 17.
3,7 · 45 + 3,7 · 55 = 3,7 · 100 = 370.

↳ Разбор примеров

Пример 1. Дроби

Найдите значение выражения (7/12 − 1/8) · 4,8.

Показать решение

Решение. 7/12 − 1/8 = 14/24 − 3/24 = 11/24. 11/24 · 4,8 = 11 · 0,2 = 2,2.

Ответ: 2,2.

Пример 2. Десятичные

Найдите значение выражения 6,8 : (1,7 − 0,9).

Показать решение

Решение. 1,7 − 0,9 = 0,8. 6,8 : 0,8 = 68 : 8 = 8,5.

Ответ: 8,5.

Пример 3. Классификация

Какие из чисел рациональные: √16; √7; 0,(3); π; −5/9?

Показать решение

Решение. √16 = 4 — целое; 0,(3) — периодическая дробь; −5/9 — дробь. √7 и π — иррациональные.

Ответ: √16; 0,(3); −5/9.

Сколько целых чисел среди чисел −7; 0; 2,5; √25; √3; 1/7?

−7, 0 и √25 = 5.

Блок Б. Посложнее

П7средний

Найдите значение выражения 1 2/3 · 0,6 − 2,5.

5/3 · 3/5 = 1; 1 − 2,5 = −1,5.
П8средний

Найдите значение выражения (1/5 + 0,15) : 0,07.

0,2 + 0,15 = 0,35; 0,35 : 0,07 = 5.
П9средний

Найдите значение выражения (2,4 · 10⁻³) · (5 · 10⁵).

12 · 10² = 1200.
П10сложнее

Запишите 0,(36) в виде несократимой обыкновенной дроби. В ответ запишите знаменатель.

x = 0,(36); 100x = 36,(36). Вычтите.
99x = 36, x = 36/99 = 4/11.
