2 Теория 10–25 мин

Алгоритм: ax² + bx + c > 0 (<, ≥, ≤)
  1. Решить уравнение ax² + bx + c = 0.
  2. Схематично нарисовать параболу: ветви по знаку a, корни на оси Ox.
  3. «> 0» — где парабола выше оси, «< 0» — где ниже.
  4. Строгий знак (>, <) — точки выколоты, нестрогий (≥, ≤) — закрашены.
x² − x − 6 < 0. Корни −2 и 3, ветви вверх, ниже оси — между корнями: (−2; 3).
x² − x − 6 ≥ 0 → (−∞; −2] ∪ [3; +∞).
Запомнить (a > 0, корни x₁ < x₂)
  • < 0 — между корнями: x₁ < x < x₂.
  • > 0 — снаружи: x < x₁ или x > x₂.
  • Если a < 0 — умножить на −1 и поменять знак неравенства.
−x² + 4x ≤ 0 → x² − 4x ≥ 0 → x(x − 4) ≥ 0 → (−∞; 0] ∪ [4; +∞).
x² < 9 — это не «x < ±3». Корни ±3, ответ (−3; 3).
D < 0: парабола не пересекает Ox При a > 0 вся парабола выше оси.
x² + 2x + 5 > 0 (D = −16) → x — любое число, (−∞; +∞).
x² + 2x + 5 < 0 → решений нет.
D = 0: парабола касается Ox ax² + bx + c = a(x − x₀)².
(x − 3)² > 0 → все x, кроме 3: (−∞; 3) ∪ (3; +∞).
(x − 3)² ≤ 0 → только x = 3 (не «нет решений»). (x − 3)² < 0 → решений нет.
ОГЭ №13: как выбрать рисунок №13
  1. Найти корни — сверить числа под точками.
  2. Закрашены или выколоты точки (≥, ≤ или >, <).
  3. Заштрихована середина или края.

Лаборатория: парабола и неравенство

1 −1 −6

Зелёным на оси Ox отмечены решения неравенства.

↳ Разбор примеров

Пример 1. Между корнями

Решите неравенство x² − 3x − 10 < 0.

Показать решение

Решение. Корни −2 и 5, ветви вверх, ниже оси — между корнями.

Ответ: (−2; 5).

Пример 2. a < 0

Решите неравенство −x² + 4x ≤ 0.

Показать решение

Решение. Умножим на −1: x² − 4x ≥ 0, x(x − 4) ≥ 0. Корни 0 и 4, нужны края, точки закрашены.

Ответ: (−∞; 0] ∪ [4; +∞).

Пример 3. D = 0

Решите неравенство x² − 6x + 9 > 0.

Показать решение

Решение. (x − 3)² > 0 — верно при всех x, кроме x = 3.

Ответ: (−∞; 3) ∪ (3; +∞).
